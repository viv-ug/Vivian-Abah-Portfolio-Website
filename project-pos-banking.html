POS & Agency Banking App

Red Tech Limited · Aug 2024 – Sep 2024

What I did

  • Designed screens for the POS terminal interface
  • Built the Agency Banking web and mobile app UI in Figma
  • Designed a monitoring dashboard for transaction oversight
  • Conducted user research sessions and usability testing
  • Created interactive prototypes for stakeholder review
