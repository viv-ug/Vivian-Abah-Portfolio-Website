Boba Bar — UX Case Study

Personal Project · Figma

Figma UX Research Wireframing Prototyping Usability Testing

A UX case study exploring the design of a boba tea ordering experience — from initial research through to a polished, interactive prototype.

The project focused on creating a delightful, intuitive ordering flow for a bubble tea brand, balancing visual personality with usability.

What I did

  • Conducted competitive analysis and user research
  • Built low-fidelity wireframes to map the ordering journey
  • Designed high-fidelity UI screens in Figma
  • Created an interactive prototype for user testing
  • Iterated on designs based on usability feedback
